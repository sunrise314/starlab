# StarLab 实战（八）：相控阵——把偏轴的 205 个邻居抹掉

## 一、先看一眼免费的午餐

第 7 章把频率维度算到了头：200 个信道的真实频谱预算下，36.4% 的链路能解调，中位 C/I 卡在 +1.8 dB，缺口只能从空间维度拿。开工之前，先看一个让我拍模型的数学结构：

把相控阵指向服务星，主瓣增益 G 对载波 C 和噪声 N 是同增同减的——C/I 公式里主瓣项精确消掉，SNR 一个分贝都不变。方向图对系统唯一的改变，是给每颗偏轴干扰卫星乘上一个相对增益 w(θ)：

```
C/I_beam = C − 10·log10( Σ P_i·w(θ_i) + N )      w(θ) = max(−12·(θ/θ_B)², 旁瓣封底)
```

这意味着两件事：第一，空分不救 SNR——好在第 6 章已经证明 SNR 中位 29.9 dB，本来就健康，这个系统是干扰受限的；第二，链路预算里那副 30 dBi 的接收天线，可以原封不动地当"指向方向的 0 dB 参考"用，模型只需要处理"偏轴压了多少"。免午餐来自守恒，先看清守恒，再动手建模。

θ_B 取 4°（Starlink 平板相控阵量级的 3dB 波束宽度），旁瓣封底 −30 dB，抛物线主瓣滚降。每颗干扰卫星的角距 θ 用它和服务星在站坐标系里的方位角、仰角算球面夹角。

## 二、三种口径，三张账单

同一份 24.7 万条可见链路（口径与第 5/6/7 章完全对齐），"波束打向哪"有三种答案，对应三张不同的账单：

- **口径 A · 全链路普查**：每条链路自带波束指向自己。这是"系统容量"视角——每 MHz 能榨出多少可用链路，可与第 7 章的全链路分布直接对比；
- **口径 B · 贪心指向**：波束打向仰角最高的星（第 5 章 greedy 的选法）。这是"站侧可用性"视角——用户什么都不挑，能不能上网；
- **口径 C · 允许重指**：每时刻挑方向性 C/I 最优的指向。这是"可用性上限"——切换层足够聪明时能拿到的最好成绩。

先看一个物理普查：每条链路的主瓣（θ < 4°）里平均挤着多少颗干扰卫星？答案是**中位 1 颗、均值 1.1、p90 = 3、max = 10**。这个数值得停下来看一眼：如果 205 颗可见星均匀铺满半球，4° 锥的立体角占比只有万分之七，期望命中应该是 0.15 颗——实测 1.1，**局部聚集让主瓣命中率比均匀假设高一个量级**。卫星在天球上不是均匀撒的，它们沿着轨道面串成珠链，而撞进你主瓣的，多半就是那条珠链上的邻居。

## 三、单信道 + 波束：204 抹掉了，还剩 1 个

T1 档（单信道 × 4° 波束）的三张账单：

| 口径 | p10 | 中位 | p90 | max | ≥9 dB 比例 |
|------|-----|------|-----|-----|------------|
| A 全链路普查 | −2.3 | 2.2 | 9.8 | 19.4 | 12.9% |
| B 贪心指向 | 10.9 | **13.3** | 14.7 | 18.8 | **93.25%** |
| C 允许重指 | 11.9 | 14.0 | 15.6 | 19.4 | **100%** |

口径 A 冷酷地复刻了第三节的普查：波束把 204 个偏轴邻居压掉 30 dB（合 0.2 颗卫星的功率），但主瓣里那颗是全额进来的——C/I 中位只到 2.2 dB，12.9% 过线。**方向图抹不掉正好撞进主瓣的干扰，这一颗只能靠频率错开。**

但口径 B 和 C 讲了一个完全不同的故事：什么都不挑、傻打仰角最高星，93.25% 的"时刻×站"直接过线；允许重指，**100% 的采样都有余量 ≥2.9 dB 的干净指向**（min 11.9 dB）。对比第 7 章单信道无波束的 0.0000%——空分单独一档，就把"站侧可用性"从死局拉到 93 分。

窄波束（T3，θ_B = 2°）顺手测了"波束宽度"这个旋钮：口径 A 中位 2.2 → 4.2（+2.0 dB），口径 B 93.25% → 98.4%。收益没有直觉期待的 6 dB（波束窄一半，主瓣内干扰期望该减 3/4），因为主瓣命中率本来就聚集在珠链上，窄波束绕不开串珠、只能削掉边缘——**旋钮收益在聚集面前提前饱和**。

## 四、频率 × 空分：两道闸门相乘

现在把第 7 章的随机 200 信道和波束叠在一起（T2）。逻辑链条是：频率复用管"谁和你同频"，波束管"谁在你主瓣里"，一颗干扰星要构成实质伤害，得**同时**撞上两道闸门——同频 ∧ 主瓣内，两个条件近似独立，概率相乘：

| 方案 | 口径 A 全链路 | 口径 B 贪心 | 口径 C 重指 |
|------|--------------|-------------|-------------|
| 单信道（第 7 章档 0） | 0.000% | — | — |
| 随机 200（第 7 章档 4） | 36.371% | — | — |
| 单信道 + 波束 4° | 12.919% | 93.250% | 100% |
| 单信道 + 窄波束 2° | 16.065% | 98.417% | 100% |
| **随机 200 + 波束 4°** | **98.754%** | **100%** | **100%** |

口径 A 从 36.4% 跳到 **98.75%**，全链路 C/I 中位 23.4 dB（p10 = 17.8，max 43.4）——"容量视角"也活了。残余的 1.25% 失败链路就是双重撞车的余数：同信道 ∧ 主瓣内同时发生（口径 A min = −2.7 dB 的那批），留给重指口径 C 去兜底（100%，中位 36.5 dB）。

两个维度各管一段的分工在这里完全显形：频率复用把"同频邻居"从 205 颗摊到 1 颗，波束把"主瓣内邻居"从 205 颗压到 1 颗，叠加之后"同频 ∧ 主瓣内"的期望从 1 掉到 0.005——**这不是 36% + 93% 的加法，是两次独立过滤的乘法**。

## 五、"Starlink 靠什么活下来"终审

三章连起来，这个问题的答案终于齐了，而且每张牌都有实测数字背书：

1. **频率复用铺基础盘**：200 信道预算，36.4% 链路可用，让系统"有得挑"（第 7 章）；
2. **相控阵保可用性**：波束 + 允许重指，任一时刻任一站 100% 有干净指向、余量 ≥2.9 dB；叠加频率复用后连容量视角都到 98.75%（本章）；
3. **切换层负责挑**：第 5 章 greedy 12.6 ms 时延、每 2 小时 1.2 万次倒手的"无脑选最高仰角"，在空分世界里已经不是将就——它就是口径 B 的 93 分。C/I 感知选择再添 7 分，但这份感知只有在干扰格局异构化之后才有意义（第 7 章还的账）。

还有一条容易被忽略的对称性：本章只算了接收端一副阵面的空分。真实系统里星上发射相控阵对邻波束用户有同样的压制，双向叠加只多不少——我们的单端模型是整个"活下来"故事的下界。

## 六、工程教训

**复合增益要算"撞车概率"，不是叠加增益。** 频率 −23 dB、空分 −20 dB 的直觉加法为什么错？因为两道闸门过滤的是同一群干扰源的不同子集，系统增益等于"P(同频) × P(主瓣内)"的乘法结构。看清过滤条件的独立性，才敢把分贝相乘。

**容量口径和可用性口径差 86 个百分点，混用就是事故。** 同一套仿真里，单信道+波束的口径 A 是 12.9%、口径 C 是 100%。汇报里只写一个数，另一张账单迟早找上门——12.9% 的系统容量撑不起 100% 的可用性承诺，反之亦然。

**免费的午餐来自守恒，先找守恒再建模。** 主瓣增益在 C/I 里精确消掉，让本章的模型只剩一个干扰加权项。如果当初硬算"30 dBi 主瓣 + 205 路干扰的绝对功率"，既容易错又什么都多不出来。

**旋钮收益在聚集面前饱和。** 窄波束理论上该白送 6 dB，实测 2 dB——因为主瓣命中本来就是珠链上的近邻事件。调参之前先看分布的聚集结构，均匀假设会高估一切"摊薄类"手段。

## 七、预设追问清单

1. 方向图真实吗？——真实相控阵有栅瓣、非抛物线滚降、扫描增益跌落；本章取理想化典型值，结论只依赖"偏轴 20~30 dB 压制"这一条量级事实；
2. 为什么不把 30 dBi 主瓣算进绝对链路预算？——它同时抬 C 和 N，C/I 与 SNR 都不变；LinkCalculator 的预算已含指向增益，方向图只以相对压制形式进入干扰项；
3. 星上波束呢？——对称的压制在发射端同样发生，本章单端模型是下界；
4. 主瓣里那颗星频率复用救得动吗？——救得动：撞主瓣 med 1 颗，200 信道把"同频"条件错开后，"同频 ∧ 主瓣内"期望掉到约 0.005 颗，口径 A 的 1.25% 残余失败就是它的余数；
5. 93.25% 和第 5 章 7.03% 在线率什么关系？——一个是站侧口径（多少时刻×站有干净链路），一个是星侧口径（多少卫星有站可看）；一个说接入，一个说覆盖，别混；
6. 干扰源为什么聚集？——可见卫星沿轨道面成串分布（第 7 章的同面串珠），局部密度比均匀球面高约 7 倍，主瓣命中从期望 0.15 涨到 1.1；
7. Starlink 真是这么干的吗？——公开资料里终端平板相控阵、星上多波束、地面 cell 频率规划三件套齐备；本章只是把三件套拆开、逐件量化；
8. 那 1.25% 死链路怎么办？——重指口径 C 100% 兜底，或者干脆弃用：容量视角下弃掉 1% 链路毫无痛感。
