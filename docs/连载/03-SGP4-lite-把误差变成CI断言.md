# StarLab 实战（三）：SGP4-lite，把误差变成一条 CI 断言

## 一、先亮成绩单，再讲我怎么把代码写错的

上一章结尾我留了个承诺：给自研的 SGP4-lite 定一个误差界，让"物理上基本正确"从一句自我评价，变成一条 CI 里跑得通的断言。这一章兑现它。先看本章结束时你将拥有的东西——对同一颗真实 ISS，自研传播器与 skyfield（业界标准的完整 SGP4 实现）24 小时逐小时对比：

| 距历元 | 位置误差 (km) | 相对轨道半径 |
|-------:|--------------:|-------------:|
| 0 h | 14.56 | 0.214% |
| 6 h | 12.49 | 0.184% |
| 12 h | 5.93 | 0.087% |
| 17 h | **14.69（最大）** | 0.216% |
| 24 h | 9.24 | 0.136% |

25 个采样点，最大误差 14.7 km，平均 9.7 km，上界 20 km 写进测试断言。这个成绩够不够？对仿真可视化绰绰有余（0.2% 的半径误差在 Cesium 上肉眼不可见），对链路预算也完全够用——第 5 章之后所有以公里为单位的几何计算，误差贡献最大的环节都不在这里。

但这一章真正想讲的不是"我做到了 14.7 km"，而是**过程里那个 5397 km 的事故**：黄金数据第一次跑出来的时候，24 小时误差是 5397 公里——卫星还在地球附近，但已经飞到隔壁轨道面去了。这个数字漂亮地暴露了我对 TLE 阻力项的想当然。把一次真实的事故复盘写成教程，比直接贴十遍正确答案有用得多。

## 二、二体模型的原罪：地球不是圆的

第 2 章的开普勒传播器假设地球是一个完美质点。真实地球的赤道半径比极半径长 21 公里——这个"腰"对 400 公里高度的 LEO 卫星意味着什么，用数字说话。

地球引力位展开的第一个修正项叫 J2（带谐系数）：

```java
// Sgp4Propagator 里的第一个物理常量
private static final double J2 = 1.08262668e-3;
```

它量级不大（千分之一），但 LEO 卫星一天绕地球 15.5 圈，每圈都被赤道鼓包"薅"两次，效应积累得飞快。J2 不改变轨道面的朝向之外的东西——它产生两个**长期（secular）进动**：

```java
// ── 2. J2 摄动 secular 速率 ──
// J2 归一化系数（ER 单位）
double J2_over_p2 = J2 * XKMPER * XKMPER / (p_km * p_km);

// Ω_dot (rad/min) —— RAAN 进动
double Omega_dot = -1.5 * n * J2_over_p2 * cosI;

// ω_dot (rad/min) —— 近地点幅角进动
double omega_dot = 0.75 * n * J2_over_p2 * (5.0 * cosI * cosI - 1.0);
```

代入 ISS 的真实根数（本章数据快照：2026-10-03 历元，n = 15.4873 圈/天，反算 a = 6798.6 km，轨道高度 420.5 km——和新闻里说的"约 420 公里"对上了）：

- **升交点赤经 Ω 每天西退 4.95°**——轨道面不是钉死在太空里的，它在缓慢旋转；
- **近地点幅角 ω 每天东进 3.69°**——椭圆长轴在轨道面内打转。

一天 5 度什么概念？二体模型算一天的卫星位置，仅这一项就让它偏离真实位置上千公里。这就是为什么第 2 章的纯开普勒传播器只能玩 Walker 虚拟星座，接真实 TLE 必须换传播器。

顺便埋个伏笔：如果倾角选得让 Ω_dot 恰好等于 -0.9856°/天（地球绕太阳公转的平均角速度），轨道面就会始终"迎着"太阳——这就是太阳同步轨道的原理，遥感卫星全靠它。J2 是搅局者，也是工具，看你站在哪边。

## 三、事故复盘：阻力项是怎么被我用错的

J2 说完了，说阻力。TLE 第一行尾部有三个看起来很唬人的字段：

| 字段 | 含义 | ISS 的值 |
|------|------|---------|
| ndot | 平均运动一阶变率（圈/天²） | .00005083 |
| nddot | 平均运动二阶变率（圈/天³） | 00000+0（为零） |
| BSTAR | 阻力系数（1/地球半径） | 10128-3 |

我的第一版代码是这样写的——注意，这不是虚构的反例，是我真实写出来、并且自我感觉良好的版本：

```java
// n_dot_drag (rad/min²): SGP4 一阶公式
// n_dot ≈ 1.5 * BSTAR * n² * p²  (BSTAR 单位: 1/ER)
double n_dot_drag = 1.5 * bstar * n * n * p_ER * p_ER;
```

"BSTAR 是阻力系数，阻力让平均运动变大，一阶效应正比于 n² 和半通径的平方"——每半句听上去都合理，组合起来就是一个 5118 倍的量级灾难。算一下账：

- **正确值**：TLE 的 ndot 已经直接给出了阻力的一阶平均运动变率，换算成 rad/min² 是 1.54×10⁻¹⁰。它让 24 小时后的平近点角多走 0.009°，对应弧长 **1.1 km**——这就是大气阻力对 ISS 一天的真实影响量级；
- **错误值**：我那个公式算出来 7.88×10⁻⁷，是正确值的 **5118 倍**。它让 24 小时后的平近点角多走 46.8°——大半圈，对应弧长 **约 5500 km**。

黄金数据实测 5397 km。理论推演和实测互相咬合的那一刻，bug 的位置就不言自明了。

错误的根源值得每个写物理代码的人记在心里：**BSTAR 不是"阻力对平均运动的一阶导数"，它只是完整 SGP4 内部重构大气密度标高时的一个输入**。完整 SGP4 用它配合 Brouwer 根数重构出一整套包含高阶项的 secular 加周期项，ndot 和 BSTAR 在那个体系里各自有精确的、和我想象完全不同的用途。而 TLE 的设计者们其实早就给了我们一条捷径——**ndot 字段本身就是"阻力对平均运动的一阶效应"这个物理量的观测值**。简化实现不需要重新发明它，直接用就行：

```java
// ── 3. 阻力 secular 速率 ──
// 一阶阻力对平近点角的效应已由 TLE 的 ndot 字段直接给出（rev/day²），
// 换算 rad/min²：rev/day² × 2π / 1440²。BSTAR 只在完整 SGP4 的高阶重构里使用。
double n_dot = el.ndot() * 2.0 * Math.PI / (XMNPDA * XMNPDA);

// ── 4. 时间推进（dtMin 分钟） ──
double M = M0 + n * dtMin + 0.5 * n_dot * dtMin * dtMin;
```

改完这一处，24 小时误差从 5397 km 降到 14.7 km——**368 倍**。没有引入任何新物理，只是停用了想当然。

## 四、skyfield 黄金数据：让物理代码敢说"正确"

现在回答那个方法论问题：14.7 km 这个数字，凭什么让读者相信？

自证永远不可信。我给自己定了个规矩：**用 skyfield 生成黄金数据（golden data），自研代码的输出对着它断言**。skyfield 是 Python 生态里最被广泛信任的天文计算库，它的 EarthSatellite 封装的就是官方 SGP4 算法（Vallado 参考实现的 C 移植）。拿它当真值，相当于拿"标准答案"给我们的"简化答案"打分。

生成器只有 30 行（`tools/golden_sgp4.py`），核心逻辑：

```python
ts = load.timescale()
sat = EarthSatellite(line1, line2, name, ts)

# 历元起 0~24h，每 1h 一个采样点（25 点）
base = sat.epoch.utc_datetime().replace(microsecond=0)
times = ts.from_datetimes([base + dt.timedelta(hours=h) for h in hours])

pos = sat.at(times).frame_xyz(itrs).km  # ITRS/ECEF，km —— 真值
```

一个细节值得点破：**采样点全部锚定在 TLE 历元之后 0~24 小时**，而不是"现在"起算。TLE 是一份带日期的快照，历元越久远误差越大——拿三天前的 TLE 传播，神仙算法也不准。锚定历元，让测试结果与运行日期彻底解耦，CI 里任何一天跑都是同一个数字。

消费真值的是这个 JUnit 测试（`Sgp4GoldenDataTest`）：

```java
OrbitalElements el = TleParser.parse(
        doc.get("name").asText(), doc.get("line1").asText(), doc.get("line2").asText());
Sgp4Propagator propagator = new Sgp4Propagator();

for (JsonNode p : doc.get("points")) {
    SatellitePosition pos = propagator.propagate(el, Instant.parse(p.get("t").asText()));
    double dx = pos.ecefX() - p.get("x").asDouble();
    // ... dy, dz 同理
    double err = Math.sqrt(dx * dx + dy * dy + dz * dz);
    maxErr = Math.max(maxErr, err);
}

assertTrue(maxErr < MAX_ERROR_KM, "SGP4-lite 24h 最大误差 " + maxErr
        + " km 超过断言上界 " + MAX_ERROR_KM + " km");
```

注意 Sgp4Propagator 是直接 `new` 出来的——它不依赖 Spring 容器，纯函数式的物理计算就该这样，测试零启动成本。

关于断言上界为什么是 20 km 而不是实测的 14.7：断言不是用来复述昨天成绩的，是用来**报警**的。留 35% 余量，是为了让"明天升级的 skyfield 改了个参考帧"、"换了颗 TLE 重新生成黄金数据"这类正常波动不至于误报，同时任何真正的物理回归（比如又把哪个系数写错一个量级）依然会被当场拦下。测试的上界是工程决策，不是物理常数。

## 五、14.7 km 里藏着的语义鸿沟

复盘没完。修好阻力项之后我发现一个更值得琢磨的现象：**h=0，也就是 TLE 历元那一刻，误差就有 14.5 km**。历元时刻的卫星位置是 TLE 的"出厂值"，理论上应该最准，为什么误差反而不是零？

先排除嫌疑。第一个怀疑对象是坐标系转换（惯性系到地固系的 GMST 旋转）。甄别方法延续了第 2 章结尾说的那个思路——**给每一层找一条"不可能是别的水"的约束**：我直接把两边拉回惯性系对比（skyfield 的 TEME 帧 vs 我们传播器的 ECI 输出）：

```text
h=0  ΔECI = (-6.8, -5.5, +11.4) km  |Δ| = 14.4 km
h=6  ΔECI = (-9.7, +0.3, +7.6) km   |Δ| = 12.4 km
h=12 ΔECI = (-5.4, -0.1, +2.1) km   |Δ| = 5.8 km
```

惯性系里误差同样是 14 km 量级，且同样随时间震荡——**GMST 转换无罪**，差异在传播模型本身。

真正的答案是轨道力学里最容易被教程跳过的一页：**TLE 里的六参数是平均根数（mean elements），而 skyfield 输出的 SGP4 结果是密切位置（osculating position）**。平均根数已经把短周期抖动抹平了——它描述的是"把几圈取平均后的轨道"；而真实卫星每一秒都处在被 J2 等摄动揉出涟漪的瞬时轨道上，涟漪幅度对 LEO 卫星就是 5~15 km。SGP4 内部把这些涟漪（短周期项）重新叠加回去，输出密切位置；我们的 lite 版只推进长期项，不重建涟漪。

所以 14.7 km 的构成其实是三层：短周期项 omission（大头，5~15 km，周期性震荡的来源）+ 高阶带谐与长周期项（小头）+ 阻力高阶效应（本例中可忽略）。**误差震荡而不增长，就是"缺周期项"的指纹；误差随 t² 增长，就是"系数错量级"的指纹**——下次你的传播器出问题，先看误差曲线的形状，再翻代码。

这个认知还有个实际收益：它解释了为什么我们的 lite 版"敢"只做这么少——对可视化与几何计算，你要的是公里级正确；要米级，就该直接上完整 SGP4（Java 有开源实现），而不是继续往 lite 里补项。工程上最贵的错误，是在错误的精度层上较劲。

## 六、跑起来

复现本章全部结果，三步：

```bash
# 1. 生成黄金数据（需要 pip install skyfield）
python tools/golden_sgp4.py tools/iss.tle src/test/resources/golden/iss-sgp4.json

# 2. 跑断言
mvn test -Dtest=Sgp4GoldenDataTest

# 3. 想看逐小时误差表，开 target/surefire-reports 下的测试输出
```

`mvn test` 的输出最后一行是整个方法论的浓缩：

```text
max error = 14.687 km, mean = 9.680 km over 25 points
Tests run: 1, Failures: 0, Errors: 0
```

从今往后，任何人（包括三个月后的我）改动传播器，只要把误差改出 20 km 上界，CI 直接红灯。物理正确性不再依赖任何人的记忆和良心。

## 七、预设追问清单

本章能支撑的面试追问，答案都在正文里：

1. J2 摄动对 LEO 卫星最直观的影响是什么？——轨道面每天西退几度（ISS 是 4.95°/天），近地点幅角同步漂移；
2. 太阳同步轨道和 J2 什么关系？——故意选倾角让 Ω_dot 等于地球公转角速度，轨道面迎着太阳；
3. TLE 里 ndot/nddot/BSTAR 各是什么？——平均运动的一阶/二阶变率 + SGP4 内部的大气标高输入；简化传播只需 ndot；
4. 你的传播器和完整 SGP4 差在哪？——短周期项、高阶带谐、长周期共振，24h 表现为 ~15 km 的周期性偏差；
5. 为什么历元时刻误差不是零？——TLE 是平均根数，SGP4 输出密切位置，语义差本身就有 5~15 km；
6. 黄金数据断言的上界怎么定？——实测最大值留 35% 余量，工程决策不是物理常数；
7. 误差曲线的形状能告诉你什么？——随 t² 增长 = 系数错量级；周期震荡不增长 = 缺周期项。
